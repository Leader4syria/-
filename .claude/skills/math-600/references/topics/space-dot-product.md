# الجداء السلمي في الفراغ، وتطبيقاته على المستقيمات والمستويات

> 🟡 مبني على المحتوى المعتاد للدرس. أول ما يتوفر الكتاب، طابق التعاريف والرموز وأرقام المبرهنات والصفحات مع الكتاب، وصحّح هون.

## الفكرة الكبيرة بسطر

**الجداء السلمي هو "كاشف التعامد".** كل سؤال فيه "عمودي"، "ناظم"، "مستوٍ"، "زاوية"، "بعد" أو "مسقط" بيرجع لجداء سلمي.

## الأدوات (بمعلم متجانس)

| الأداة | الصيغة | ليش منحتاجها |
|---|---|---|
| الجداء السلمي | u(x,y,z)·v(x',y',z') = xx' + yy' + zz' | الحساب السريع |
| الصيغة الهندسية | u·v = ‖u‖‖v‖cos θ | الزاوية ومعنى الإشارة |
| النظيم | ‖u‖ = √(x²+y²+z²)، وAB = ‖AB→‖ | الأطوال |
| التعامد | u ⊥ v ⇔ u·v = 0 | **أهم وحدة** |
| معادلة المستوي | P يمر بـ A وناظمه n(a,b,c): AM→·n = 0 ⇔ ax+by+cz+d = 0 | |
| قراءة الناظم | من ax+by+cz+d = 0، الناظم n(a,b,c) | |
| بعد نقطة عن مستوٍ | d(M, P) = \|ax₀+by₀+cz₀+d\| / √(a²+b²+c²) | |

### ليش معادلة المستوي هيك؟ (الـ"ليش" اللي لازم يفهمها الطالب)
المستوي هو **كل النقاط M** اللي الشعاع AM→ فيها نايم بالمستوي. وأي شعاع نايم بالمستوي عمودي على الناظم n. إذن:
M ∈ P ⇔ AM→ ⊥ n ⇔ AM→·n = 0 ⇔ a(x−x_A) + b(y−y_A) + c(z−z_A) = 0.
ولما منفك القوسين، الثوابت كلها بتتجمع بـ d، فبتطلع ax + by + cz + d = 0. **عشان هيك أمثال x وy وz هي مركبات الناظم.**

|---|---|---|

| "أثبت أن المثلث قائم في A" | AB→·AC→ = 0 | الضلعين حول الزاوية |
| "احسب الزاوية / cos الزاوية" | cos θ = u·v / (‖u‖‖v‖) | الصيغة الهندسية |
| "اكتب معادلة المستوي المار بـ A والعمودي على u" | n = u، وعوّض A لتلاقي d | الناظم معطى |

| "مجموعة النقاط M حيث MA→·MB→ = 0" 🟡 | كرة قطرها [AB] | زاوية AMB قائمة |

## المثال المرجعي (سؤال 6 من لوح الطالب)

**المعطيات:** A(2,−1,0)، B(−1,3,5)، P: 2x − 3y + z − 5 = 0.
① أثبت أن (AB) يقطع P. ② عيّن إحداثيات نقطة التقاطع C.

**① الربط:** "يقطع" تعني **مو موازي**. والموازاة بتنكشف بالتعامد مع الناظم، يعني بالجداء السلمي.
n(2,−3,1)، AB→(−3,4,5)، n·AB→ = −6 − 12 + 5 = −13 ≠ 0، إذن (AB) غير موازٍ لـ P، فيقطعه في نقطة وحيدة.

**② الربط:** C لازم تحقق شرطين: (على المستقيم) و(على المستوي). الشرط الأول بيعطي x وy وz بدلالة λ، والتاني بيعطي معادلة بمجهول واحد.
AC→ = λ·AB→ ← x = 2 − 3λ، y = −1 + 4λ، z = 5λ.
بالتعويض: 2(2−3λ) − 3(4λ−1) + 5λ − 5 = 0 ← −13λ + 2 = 0 ← λ = 2/13.
إذن C(20/13, −5/13, 10/13). **تحقق:** 40/13 + 15/13 + 10/13 = 65/13 = 5 ✓

**نظرة للخلف:** أمثال λ بعد التعويض (−13) هو نفسه n·AB→. لهيك إذا n·AB→ = 0، λ بتختفي، فيا ما في حل (موازٍ) يا كل λ حل (محتوى). **هاد هو الرابط بين الطلبين.**

**طرق بديلة ضمن المنهاج:** البدء من B (BC→ = t·AB→ بتعطي t = −11/13)، أو شعاع توجيه BA→، أو C مرجح لـ A وB. كلها بتعطي نفس C.

## توائم مُتحقَّق منها (sympy)

1. A(−1,4,−5)، B(0,3,−3)، P: x + 2y + z − 4 = 0.
   n·AB→ = 1 ≠ 0، λ = 2، C(1,2,−1).
2. **حالة خاصة:** A(1,0,0)، B(2,1,0)، n(1,−1,3) ← n·AB→ = 0.
   - مع P: x − y + 3z − 1 = 0: A ∈ P، إذن (AB) **محتوى** في P.
   - مع P: x − y + 3z + 2 = 0: A ∉ P، إذن (AB) **موازٍ تماماً** لـ P.
3. **بعد ومسقط:** M(1,1,1)، P: 2x − y + 2z + 3 = 0.
   d(M,P) = |2 − 1 + 2 + 3| / 3 = 2. المسقط: H = M + t(2,−1,2) ← 9t + 6 = 0 ← t = −2/3 ← H(−1/3, 5/3, −1/3). تحقق: MH = |t|·‖n‖ = 2 ✓

## الفخاخ

- n·u = 0 **ما بتعني** "ما في تقاطع" بشكل مطلق، لأنه في احتمال **محتوى**. لازم تعوّض نقطة.
- الخلط بين **شعاع التوجيه** (للمستقيم) و**الناظم** (للمستوي).
- نسيان d بمعادلة المستوي، أو قراءة الناظم من معادلة مو مرتبة (مثلاً 2x = 3y − z + 5: لازم ترتّب أولاً).
- بصيغة البعد: نسيان القيمة المطلقة، أو نسيان الجذر بالمقام.
- الإشارات بـ AB→ = B − A (مو A − B).
- بالتمثيل الوسيطي: النتيجة هي **النقطة** مو λ. لا توقف عند λ.

## أسئلة "ليش" للشرح الذاتي

- ليش الناظم عمودي على **كل** شعاع بالمستوي، مو بس على شعاع واحد؟
- ليش بيكفي شعاعين غير مرتبطين خطياً لنحدد الناظم؟
- ليش d(M,P) فيها قيمة مطلقة؟ (شو معنى الإشارة؟ M بأي جهة من P)
- ليش إذا n وu مرتبطين خطياً، المستقيم عمودي على المستوي؟
