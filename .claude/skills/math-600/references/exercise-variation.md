# تغيير أرقام التمارين بأمان (التوائم)

الهدف: تمرين **بنفس البنية والفكرة** بس بأرقام جديدة، لحتى يتدرب الطالب على الطريقة مو على حفظ الجواب.

## القواعد

1. **ثبّت البنية:** نفس المطلوب، نفس عدد الطلبات، ونفس الأداة.
2. **غيّر شي واحد بالأول** (نظرية التنويع)، وبعدين كذا شي.
3. **صمّم من الجواب للسؤال:** اختار جواب "حلو" (أعداد صحيحة أو كسور بسيطة)، وابني المعطيات منه.
   - مثال: بدك تقاطع مستقيم مع مستوٍ بنقطة صحيحة؟ اختار C، اختار شعاع توجيه u، وخذ A = C − 2u وB = A + u، واختار n مع n·u ≠ 0، وd = −n·C.
4. **احفظ الحالة:** إذا التمرين الأصلي فيه حالة "يقطع"، التوأم لازم كمان "يقطع" (إلا إذا قصدك تدرّب على الحالة التانية وقلتله).
5. **تحقّق إجباري بـ Python/sympy** قبل ما تعطي التمرين:
   ```python
   from sympy import *
   # مثال: تقاطع (AB) مع P
   A=Matrix([2,-1,0]); B=Matrix([-1,3,5]); n=Matrix([2,-3,1]); d=-5
   l=symbols('l'); M=A+l*(B-A)
   sol=solve(n.dot(M)+d,l)[0]; print(sol, list(M.subs(l,sol)))
   ```
   (إذا sympy مو منصّب: `pip install sympy`)
6. **سمِّ التوأم:** "توأم تمرين 6 (أرقام مغيّرة)" حتى ما يختلط مع تمارين الكتاب الأصلية.

## درجات التنويع (من الأسهل للأصعب)

| الدرجة | شو منغيّر | مثال (تقاطع مستقيم ومستوٍ) |
|---|---|---|
| 1 | الأرقام فقط | نقاط ومستوٍ جديدين، نفس الأسئلة |
| 2 | شكل المعطى | المستقيم معطى بتمثيل وسيطي بدل نقطتين |
| 3 | السؤال المعاكس | "عيّن m لحتى يكون المستقيم موازياً للمستوي" |
| 4 | الحالة الخاصة | n·u = 0: ميّز بين موازٍ ومحتوى (عوّض A) |
| 5 | الدمج | التقاطع + بعد نقطة عن المستوي + المسقط القائم |
